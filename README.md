# Supply Chain Optimization Audit: SC Networks Global

📌 Project Overview
This project is a comprehensive data-driven audit of 10,300+ shipments aimed at identifying operational inefficiencies and financial risks within a global supply chain. Using a combination of SQL, Excel, and Power BI, I identified critical bottlenecks and developed a strategic mitigation plan for high-value cargo.

🚀 Key Insights
* Operational Bottleneck: Identified a major 159-day logistics delay within US trucking routes.

* Financial Risk Audit: Discovered $120M in uninsured high-value shipments (>$50k per unit).

* Freight Efficiency: Analyzed freight costs across Air, Ocean, and Truck modes to identify the top 3 most expensive shipping corridors.

🛠️ Technical Workflow
* Data Cleaning & Validation (Excel): Processed raw delivery history and validated SQL query results against master records.

* Advanced Analytics (SQL): Developed scripts for logistics auditing, freight cost efficiency, and vendor performance.

* Data Visualization (Power BI): Built an Integrated Supply Chain Control Center with 7 pages of deep-dive insights.

* Strategic Reporting (PowerPoint): Consolidated findings into a 9-slide executive presentation with actionable recommendations.

📂 Repository Structure
* /Data: Raw and validated datasets.

* /SQL_Scripts: Numbered analytical queries used for the audit.

* /Dashboard: Power BI .pbix file and visual previews.

* /Presentation: Final Executive Summary and Strategic Action Plan.
